# 规则消融测试（T-60，扩展样本）

- 样本：2718 场（2025-08-16 → 2026-11-09）
- 方法：每条比赛只取一次数据、构建一次特征；关闭规则后**重新评分**（方向/置信度/仓位都会变），不是对 CSV 做事后过滤。
- 主口径：`conf50_giving`（让球方 + 置信度≥50）；对照：`conf50_all`（不加盘口过滤）。
- 显著性：ROI 用两样本均值近似；命中率用两比例 z 检验。p<0.05 才算统计上可区分。

## 2. 不加盘口过滤（conf50_all）

## 3. 结论

1. **能提高“整体命中率”的删法存在，但会牺牲让球方 edge**：
   - 删 `EURO_ASIA_ALIGN`：`conf50_all` 命中率 50.6% → 55.4%，ROI -3.2% → +4.4%（p≈0.24，不显著）。
   - 删 `MOV_WATER_ONLY`：`conf50_all` 命中率 50.6% → 54.5%，ROI -3.2% → +3.6%（p≈0.29，不显著）。
   - 下注数同时从 479 降到 262 / 258；而这两个规则正是**让球方 edge 的主要来源**：删掉后 `conf50_giving` 从 +14.2% 掉到 +6.4% / +5.5%。
2. **只做让球方时，删“已知坏规则”小幅提升，但月度不稳定**：
   - `drop_known_bad`（关闭 T02、WL_UPPER_099、MOV_RETREAT_WATER_UP、T01_EARLY_DEEPEN_FAV、MOV_DEEPEN_SUPPORT）：
     288 → 316 注，命中率 60.7% → 62.2%，ROI +14.2% → +16.3%，三个时期全部改善。
   - 单独删 `T01_EARLY_DEEPEN_FAV` 就能拿到 +16.0% / 62.1% / 320 注，是改动最小的候选。
   - 这 +2.1pp 的提升几乎全部来自 `T01_EARLY_DEEPEN_FAV`；`MOV_DEEPEN_SUPPORT` 只有约 +0.3pp，`T02_RETREAT_LOW_WATER` / `WL_UPPER_099` / `MOV_RETREAT_WATER_UP` 在本口径下对下注没有影响。
   - 但月度看是 8 个月变好、4 个月变差、2 个月持平；ROI 提升 +2.1pp 的 p≈0.76，命中率 +1.5pp 的 p≈0.71，**统计上不可区分**。
   - 元 walk-forward 在 2025-11 后能选出该版本，拼接 ROI +16.2%（vs 全程 baseline +14.2%），方向一致但仍非独立验证。
3. **四条规则的核心组合在本样本上复现了相同结果**：只保留 `EURO_FAV_DRIFT + WL_UPPER_LOW + EURO_ASIA_ALIGN + MOV_WATER_ONLY`，与 `drop_known_bad` 完全一致（316 注 / 62.2% / +16.3%）。这说明其余方向性规则在本样本中几乎没有净贡献，但不等于它们在其他样本中无效。
4. **风险/观察过滤器几乎不影响下注**：关闭 DQ、WATER_DIVERGENCE、COMPANY_DIVERGENCE、MACAU_OPPOSITE、高水规则后，让球方结果完全不变；它们不是命中率的拖累，建议保留。
5. **`only_drift_low`（只留欧赔漂移 + 上盘低水）**：117 注、62.0% 命中、+13.2% ROI，p(hit)≈0.03，但样本只有 117 注，且本质上是“只做上盘/让球方”的另一种写法，不能和 baseline 全样本直接比较。
6. **总体判断**：删规则确实可以把命中率做高，但主要机制是**减少下注、挑更容易的场次**，而不是模型变强；在推荐口径（让球方 + conf≥50）下，删规则只带来约 +1.5pp 命中和 +2.1pp ROI，且不显著。即使是 4 规则核心组合，`conf50_all` 仍只有 -0.3% ROI——**让球方过滤才是主要 edge，删规则不能替代它**。**不能据此直接改默认**。

## 4. 建议

- 最小改动候选是删 `T01_EARLY_DEEPEN_FAV`；先纸面跟踪验证。当前 CLI 没有保留消融开关，复跑需临时加参数。
- 如果要更彻底的简化，用 4 规则核心组合做实验 profile；但先做月度 walk-forward，再决定是否设为默认。
- 保留 `EURO_ASIA_ALIGN` / `MOV_WATER_ONLY`：它们提高的是让球方 ROI，不是整体命中率。
- 不要为了“整体命中率”删这两条规则；那会把一个正期望的让球方策略换成样本更小的另一个策略。

## 6. 元 walk-forward：baseline vs 删已知坏规则

每个月只用之前月份累计 ROI 在 `baseline` 与 `drop_known_bad` 之间选择：

- 2025-08 / 2025-09 / 2025-10：选择 `baseline`
- 2025-11 起：持续选择 `drop_known_bad`
- 拼接结果：**312 注，利润 +50.52，ROI +16.2%**
- 对照：全程 `baseline` 288 注 / +40.95 / +14.2%；全程 `drop_known_bad` 316 注 / +51.62 / +16.3%

也就是说，删规则版本在 2025-11 之后能被样本外选中，拼接结果优于不删；但前三个月仍按 baseline 承担了 2025-10 的 -14.6%。这比全样本直接比较更有说服力，但候选规则集仍是看过数据后提出的，不能当作完全独立验证。
